## vision_system 项目（四轴机械臂视觉系统）

**技术栈：** Eye-to-Hand 视觉方案，USB UVC 摄像头 + CH347F(USB→I2C) + PCA9685 + RDS3235 舵机×4  
**检测方式：** HSV 颜色检测 / ArUco 标记 / YOLOv8 自定义模型  
**坐标变换：** 平面约束法（主）+ 单应矩阵法（备）  
**语音控制：** Vosk 离线中文语音识别 + pyttsx3 TTS 反馈
