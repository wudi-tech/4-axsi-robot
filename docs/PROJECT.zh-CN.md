# 基于视觉与多模态交互的四轴机械臂宠物系统

项目面向桌面人机交互场景，融合目标检测、语音识别与机械臂控制，实现物品识别、抓取及拟猫互动。实物项目已经完成并上交；本仓库整理最终应用源码和可核查的已有结果，本次没有新增硬件测试。

## 团队与个人贡献

本项目为团队项目，本人负责视觉感知、多模态交互与系统集成，完成从图像采集、目标定位到交互决策及机械臂执行接口的流程整合。仓库保留团队项目运行所需的控制和驱动模块，以呈现完整应用链路；这些文件的存在不代表整机机构、电路与底层控制全部由本人独立完成。逐文件作者与其他成员具体分工不在现有材料中推断。

- **视觉感知与定位：** 基于 YOLOv8 训练并部署三类桌面物品检测模型，利用 OpenCV 完成相机内参标定、畸变校正与平面单应变换，将像素坐标映射至机械臂工作平面。
- **多模态交互：** 集成 Vosk 离线中文语音识别与 MediaPipe 人手检测，设计拟猫交互流程，实现目标指令解析、随机试探、用户反馈纠错及奖励动作，并提供独立键盘控制模式。
- **系统集成：** 整合相机采集、目标检测、坐标转换、交互决策与机械臂控制接口，串联识别、抓取和放置；相机后台线程持续采集最新帧，训练、标定与调试工具独立放入 `tools/`。

## 核心交互

拟猫模式不是只取置信度最高的指定目标。系统把检测物体作为候选集合，随机尝试其中一个，由用户判断“真棒/不对”。错误反馈触发放回和换目标；正确反馈触发固定区域放置、人手奖励动作和回正。这种反馈式试探形成项目的互动特点。

`tried_ids` 在一次候选列表内记录已尝试索引，并非跨帧目标跟踪。奖励动作使用预设正弦摆动，未检测到手时会退化到固定位置；不能描述成已验证的接触感知或学习策略。

## 归档内容

`main.py` 为正式入口，`vision_pipeline.py` 为视觉管道；`camera/`、`detection/`、`transform/`、`robot/`、`config/`、`utils/` 为应用模块，`tools/` 为维护工具。仓库同时保留原技术路线图、两份数值标定文件、关联视觉训练实验的历史 CSV 与本次离线核验记录。

历史报告曾写“待实机联调”和“复训权重待同步”。前者不覆盖后续用户确认的实物已完成并上交；后者已通过当前本地权重哈希重新核对，详见结果文档。旧报告中的主观语音准确率和未经量化的硬件表现不作为本仓库的定量结果。
