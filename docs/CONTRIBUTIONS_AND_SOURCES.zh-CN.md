# 来源、版权与归档边界

## 贡献表述

本项目为团队项目。本人负责视觉感知、多模态交互及系统集成，具体范围见 [项目介绍](PROJECT.zh-CN.md)。控制/驱动应用源码保留是为了展示完整系统接口和团队实现，不把整机运动控制、机构、电路及全部文件署名归为个人贡献。

本次归档从现有工作目录选取应用源码，保留文件内的原注释和已有声明；没有发现可以据此为全部项目应用源码新增统一许可证的现成授权文件，因此不虚构 MIT、Apache 或其他整仓许可证，也不改写原权属。第三方依赖仍分别遵守其条款；公开展示不自动授予第三方资产再分发权。

## 技术来源

| 来源 | 项目中用途 | 归档处理 |
|---|---|---|
| [OpenCV](https://docs.opencv.org/4.x/) | 相机、内参标定、去畸变、homography、预览 | Python 调用代码保留，库通过依赖安装 |
| [Ultralytics YOLOv8](https://docs.ultralytics.com/models/yolov8/) | 检测、训练与验证 | 调用代码保留，不打包库和模型；使用时自行核对适用许可 |
| [Vosk](https://alphacephei.com/vosk/) / [模型页](https://alphacephei.com/vosk/models) | 离线中文关键词识别 | 调用代码保留，语音模型和 ZIP 排除 |
| [Google MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker) | 人手关键点 | 调用代码及其官方模型 URL 保留，不附模型 |
| [WCH CH347](https://github.com/WCHSoftGroup/ch347) | Windows USB-I2C 接口 | 项目 Python 封装保留，官方 DLL/SDK 与驱动不打包 |
| [NXP PCA9685](https://www.nxp.com/) | PWM 控制器 | 项目 Python 应用驱动保留，不附厂商资料全集 |
| 其他 Python 依赖 | 数值、TTS、拼音、音频、标注等 | 见原 `requirements.txt`；不再分发其安装环境 |

这些链接用于标识原依赖来源，并不代表本次对其最新版本或条款进行了在线核验。原源码的 `ku.py` 来源注释保留在舵机映射/控制中；旧实验入口本身未混入正式运行入口。

## 选入

- 正式 `main.py`、`vision_pipeline.py` 与应用模块全部相关 Python 文件。
- 标定、训练、采集、标注转换和调试维护工具；原硬件/标定/tools 指南作为辅助资料。
- `dataset.yaml` 的类别/路径配置；两份仅含数值的历史标定文件。
- 原技术路线 PNG/SVG；关联训练实验的纯数值 CSV，与自动提取的证据摘要。
- 本次新写英文 README 和中文项目、架构、运行、结果、贡献来源文档。

入选原代码与数值文件按 SHA-256 核对；唯一源码文本差异是 `tools/test_hand_detection.py` 顶部用法注释的私人绝对路径改成相对命令，AST 执行语句保持一致，不修改动作参数。`evidence/archive_files.json` 列出归档文件大小与哈希；本地详细源路径映射仅保存在协调工作区，不公开私人路径。

- WCH DLL/SDK/驱动、第三方预训练模型、自定义权重和 Vosk 模型包。
- 原始训练图像、标注全集、含数据图像的训练拼图和未知授权数据集。
- `main1.py`、临时测试脚本及 `ku.py` 旧入口等重复/实验文件；当前所需映射已经保留在应用源码中。
- 旧 `PROJECT.md` 和两份 Word 报告及历史长报告未直接作为最终说明公开：其中含旧状态、主观指标和旧机器路径，已据当前源码、原结果与用户确认版重写本仓库资料。它们仍保留在原工程。
- 原始聊天、个人申请材料、凭据、未明用途的私有文件和与项目无关资料。

本仓库是精选应用与证据归档，不是原开发磁盘的完整备份。原工程保持原状；没有为公开归档执行设备控制。
